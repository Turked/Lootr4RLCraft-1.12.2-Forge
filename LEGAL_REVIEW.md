- [ ] Confirm the copyright holder and the terms under which the original project will be distributed. The development copyright notice uses MechGaming.
- [ ] Clear the provisional name Lootr4RLCraft for public distribution, obtain any needed permissions, or adopt a distinct name. A non-affiliation statement does not clear the name. [USPTO guidance on likelihood of confusion](https://www.uspto.gov/trademarks/search/likelihood-confusion)
- [ ] Verify that a clean checkout and the JAR contain only the independent project, plus any separately authorized materials and required notices. The separate upstream Lootr checkout has its own MIT notice and stays outside the build. [Lootr license scope](https://www.curseforge.com/minecraft/mc-mods/lootr/license)
- [ ] Review dependency, build tool and resource provenance against `THIRD_PARTY_NOTICES.md` and `ASSET_PROVENANCE.md`.
- [ ] Verify the project page, artwork, JAR metadata and installation instructions describe the project as independent and follow the [Minecraft Usage Guidelines](https://www.minecraft.net/en-us/usage-guidelines).
- [ ] Complete the technical test matrix before producing a release build.
